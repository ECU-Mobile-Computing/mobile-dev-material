# MAUI Runtime IDs

| Platform | Valid RIDs |
| --- | --- |
| **Windows** | win-x64, win-arm64 |
| **Android** | android-arm, android-arm64, android-x86, android-x64 |
| **iOS (device)** | ios-arm, ios-arm64 |
| **iOS (simulator)** | iossimulator-x86, iossimulator-x64 |
| **Mac Catalyst** | maccatalyst-x64, maccatalyst-arm64 |
| **macOS** | osx-x64, osx-arm64 |
