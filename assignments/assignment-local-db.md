# Assignment: Build a Local Notes App with .NET 11 MAUI and SQLite

## Overview

Build a single-page .NET 11 MAUI app that stores notes in an embedded SQLite database. The user can create, read, update, and delete notes. The data remains available after the app closes and restarts.

This is a guided assignment for students who are new to local databases. Complete the sections in order and verify each checkpoint before continuing.

No web server, internet connection, account, API key, or remote database is required.

## Learning outcomes

By the end of this assignment, you should be able to:

- explain what an embedded database is
- explain where a MAUI app stores private local files
- add SQLite to a .NET 11 MAUI project
- map a C# class to a SQLite table
- implement asynchronous create, read, update, and delete operations
- separate database, view model, and user-interface responsibilities
- register services with dependency injection
- display database records with a `CollectionView`
- verify that data persists after an app restart

## What is an embedded database?

An embedded database runs inside the application process. The app reads and writes a local database file directly instead of sending HTTP requests to a database server.

This assignment uses SQLite because it is small, reliable, and supported on the platforms targeted by .NET MAUI.

```text
MainPage.xaml
      |
      | data binding and commands
      v
MainViewModel
      |
      | asynchronous method calls
      v
NoteDatabase
      |
      | sqlite-net-pcl
      v
notes.db3 in FileSystem.AppDataDirectory
```

The SQLite file belongs only to this app. Other apps should not access it directly.

> Important: local storage is not the same as cloud storage. Notes remain on the current device, are not automatically synchronized, and are normally removed when the app is uninstalled.

## Application behavior

The finished app will allow a user to:

1. type a note and select **Save note**
2. see the saved note in a list
3. select an existing note, edit its text, and save the change
4. select a note and delete it
5. close and reopen the app without losing saved notes

## 4. Create the database model

Create a `Models` folder inside `src/LocalNotes.App`. Create `Models/Note.cs`:

```csharp
using SQLite;

namespace LocalNotes.App.Models;

public sealed class Note
{
	[PrimaryKey, AutoIncrement]
	public int NoteId { get; set; }

	[MaxLength(500)]
	public string Text { get; set; } = string.Empty;

	public DateTime CreatedAtUtc { get; set; }
}
```

### How the model becomes a table

The `Note` class describes one database row. By default, sqlite-net uses the class name as the table name and the public properties as columns.

| C# member | SQLite purpose |
| --- | --- |
| `Note` | table |
| `NoteId` | integer primary key generated by SQLite |
| `Text` | note content with a maximum mapped length of 500 |
| `CreatedAtUtc` | creation timestamp stored in UTC |

`NoteId` starts at `0` for a new object. After a successful insert, SQLite assigns the NoteId and sqlite-net updates the object.

The model contains data only. It does not know about pages, buttons, or dependency injection.

## 5. Create the database service

Create a `Data` folder inside `src/LocalNotes.App`. Create `Data/NoteDatabase.cs`:

```csharp
using LocalNotes.App.Models;
using Microsoft.Maui.Storage;
using SQLite;

namespace LocalNotes.App.Data;

public sealed class NoteDatabase
{
	private readonly SQLiteAsyncConnection database;
	private readonly Task initialization;

	public NoteDatabase()
	{
		var databasePath = Path.Combine(FileSystem.AppDataDirectory, "notes.db3");

		database = new SQLiteAsyncConnection(
			databasePath,
			SQLiteOpenFlags.ReadWrite |
			SQLiteOpenFlags.Create |
			SQLiteOpenFlags.SharedCache);

		initialization = database.CreateTableAsync<Note>();
	}

	public async Task<List<Note>> GetNotesAsync()
	{
		await initialization;
		return await database.Table<Note>()
			.OrderByDescending(note => note.CreatedAtUtc)
			.ToListAsync();
	}

	public async Task<int> SaveNoteAsync(Note note)
	{
		await initialization;

		return note.NoteId == 0
			? await database.InsertAsync(note)
			: await database.UpdateAsync(note);
	}

	public async Task<int> DeleteNoteAsync(Note note)
	{
		await initialization;
		return await database.DeleteAsync(note);
	}
}
```

### Why the database path matters

`FileSystem.AppDataDirectory` returns the app's private, writable data directory on the current platform. Do not put a writable database in `Resources/Raw`, and do not hard-code a Windows, Android, or macOS path.

The actual directory differs by platform, but the MAUI API keeps the application code the same.

### Why initialization is stored as a task

`CreateTableAsync<Note>()` creates the table only if it does not already exist. Keeping its task in the service ensures every operation waits for initialization without repeatedly creating the table.

### How CRUD maps to the service

| CRUD operation | Service code |
| --- | --- |
| Create | `InsertAsync(note)` |
| Read | `Table<Note>().ToListAsync()` |
| Update | `UpdateAsync(note)` |
| Delete | `DeleteAsync(note)` |

`SaveNoteAsync` chooses insert or update by inspecting the primary key. An NoteId of `0` means the note has not been inserted yet.

## 6. Create the view model

Create a `ViewModels` folder inside `src/LocalNotes.App`. Create `ViewModels/MainViewModel.cs`:

```csharp
using System.Collections.ObjectModel;
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;
using LocalNotes.App.Data;
using LocalNotes.App.Models;

namespace LocalNotes.App.ViewModels;

public partial class MainViewModel : ObservableObject
{
	private readonly NoteDatabase database;

	public ObservableCollection<Note> Notes { get; } = [];

	[ObservableProperty]
	[NotifyCanExecuteChangedFor(nameof(SaveCommand))]
	private string draftText = string.Empty;

	[ObservableProperty]
	[NotifyCanExecuteChangedFor(nameof(DeleteCommand))]
	private Note? selectedNote;

	[ObservableProperty]
	[NotifyCanExecuteChangedFor(nameof(SaveCommand))]
	[NotifyCanExecuteChangedFor(nameof(DeleteCommand))]
	private bool isBusy;

	[ObservableProperty]
	private string statusMessage = "Loading local notes...";

	public MainViewModel(NoteDatabase database)
	{
		this.database = database;
	}

	partial void OnSelectedNoteChanged(Note? value)
	{
		if (value is null)
			return;

		DraftText = value.Text;
		StatusMessage = $"Editing note {value.Id}.";
	}

	private bool CanSave() => !IsBusy && !string.IsNullOrWhiteSpace(DraftText);

	private bool CanDelete() => !IsBusy && SelectedNote is not null;

	[RelayCommand]
	private async Task LoadAsync()
	{
		if (IsBusy)
			return;

		try
		{
			IsBusy = true;
			await ReloadNotesAsync();
			StatusMessage = Notes.Count == 0
				? "No notes yet. Add the first note."
				: $"Loaded {Notes.Count} note(s) from this device.";
		}
		catch (Exception ex)
		{
			StatusMessage = $"Could not load notes: {ex.Message}";
		}
		finally
		{
			IsBusy = false;
		}
	}

	[RelayCommand(CanExecute = nameof(CanSave))]
	private async Task SaveAsync()
	{
		try
		{
			IsBusy = true;

			var note = SelectedNote ?? new Note
			{
				CreatedAtUtc = DateTime.UtcNow
			};

			note.Text = DraftText.Trim();
			var isNew = note.NoteId == 0;
			await database.SaveNoteAsync(note);
			await ReloadNotesAsync();
			ClearEditor();
			StatusMessage = isNew ? "Note saved locally." : "Note updated locally.";
		}
		catch (Exception ex)
		{
			StatusMessage = $"Could not save the note: {ex.Message}";
		}
		finally
		{
			IsBusy = false;
		}
	}

	[RelayCommand(CanExecute = nameof(CanDelete))]
	private async Task DeleteAsync()
	{
		if (SelectedNote is not { } note)
			return;

		try
		{
			IsBusy = true;
			await database.DeleteNoteAsync(note);
			await ReloadNotesAsync();
			ClearEditor();
			StatusMessage = "Note deleted from this device.";
		}
		catch (Exception ex)
		{
			StatusMessage = $"Could not delete the note: {ex.Message}";
		}
		finally
		{
			IsBusy = false;
		}
	}

	[RelayCommand]
	private void NewNote()
	{
		ClearEditor();
		StatusMessage = "Ready for a new note.";
	}

	private async Task ReloadNotesAsync()
	{
		var savedNotes = await database.GetNotesAsync();
		Notes.Clear();

		foreach (var note in savedNotes)
			Notes.Add(note);
	}

	private void ClearEditor()
	{
		SelectedNote = null;
		DraftText = string.Empty;
	}
}
```

### How the view model works

- `ObservableCollection<Note>` tells the UI when rows are added or removed.
- `[ObservableProperty]` generates public bindable properties.
- `[RelayCommand]` generates `LoadCommand`, `SaveCommand`, `DeleteCommand`, and `NewNoteCommand`.
- `CanSave` prevents saving blank text or saving during another operation.
- `CanDelete` requires a selected note.
- Selecting a note copies its text into the editor.
- `ReloadNotesAsync` refreshes the list from the database after each change.

The view model catches database errors and exposes a readable status message. The database service does not display alerts or manipulate controls.

Create a `Views` folder inside `src/LocalNotes.App`. Create `Views/MainPage.xaml`:

```xml

	x:DataType="vm:MainViewModel"
	xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
	xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"

		Padding="20"

		<Label
			Grid.Row="0"
			Text="Local Notes"

			FontSize="28"

		<Entry
			Grid.Row="1"
			AutomationId="NoteEntry"
			Text="{Binding DraftText, Mode=TwoWay}"

		<Grid
			Grid.Row="2"
			ColumnDefinitions="*,*,*"
			ColumnSpacing="8">

				Grid.Column="0"
				AutomationId="SaveNoteButton"
				Text="Save note"
				Command="{Binding SaveCommand}" />
			<Button
				Grid.Column="1"
				AutomationId="NewNoteButton"
				Text="New"
				Command="{Binding NewNoteCommand}" />
			<Button
				Grid.Column="2"
				AutomationId="DeleteNoteButton"
				Text="Delete"
				Command="{Binding DeleteCommand}" />
		</Grid>

		<Grid Grid.Row="3" ColumnDefinitions="*,Auto" ColumnSpacing="12">
			<Label
				VerticalOptions="Center"
				Text="{Binding StatusMessage}"
				LineBreakMode="WordWrap"
				SemanticProperties.LiveSetting="Polite" />
			<ActivityIndicator
				Grid.Column="1"
				IsRunning="{Binding IsBusy}"
				IsVisible="{Binding IsBusy}" />
		</Grid>

		<CollectionView
			Grid.Row="4"
			AutomationId="NotesList"
			ItemsSource="{Binding Notes}"
			SelectedItem="{Binding SelectedNote, Mode=TwoWay}"
			SelectionMode="Single">
			<CollectionView.EmptyView>
				<Label
					Text="Saved notes will appear here."
					HorizontalOptions="Center"
					VerticalOptions="Center" />
			</CollectionView.EmptyView>
			<CollectionView.ItemTemplate>
				<DataTemplate x:DataType="models:Note">
					<Border
						Margin="0,4"
						Padding="12"
						Stroke="{AppThemeBinding Light=#B8B8B8, Dark=#666666}"
						StrokeShape="RoundRectangle 6"
						StrokeThickness="1">
						<Grid RowDefinitions="Auto,Auto" RowSpacing="4">
							<Label
								Text="{Binding Text}"
								FontSize="17"
								LineBreakMode="WordWrap" />
							<Label
								Grid.Row="1"
								Text="{Binding CreatedAtUtc, StringFormat='Saved {0:u}'}"
								FontSize="12"
								Opacity="0.75" />
						</Grid>
					</Border>
				</DataTemplate>
			</CollectionView.ItemTemplate>
		</CollectionView>
	</Grid>
</ContentPage>
```

### Layout explanation

The outer `Grid` reserves its final `*` row for the list. This gives `CollectionView` a bounded area where it can scroll and virtualize records correctly.

Do not put the `CollectionView` inside a `VerticalStackLayout` or `ScrollView`. That can break measurement, scrolling, and virtualization.

`x:DataType` enables compiled bindings on both the page and the item template. Compiled bindings catch many property-name mistakes at build time and are faster than reflection-based bindings.

Create `Views/MainPage.xaml.cs`:

```csharp
using LocalNotes.App.ViewModels;

namespace LocalNotes.App.Views;

public partial class MainPage : ContentPage
{
	private readonly MainViewModel viewModel;

	public MainPage(MainViewModel viewModel)
	{
		InitializeComponent();
		BindingContext = viewModel;
		this.viewModel = viewModel;
	}

	protected override async void OnAppearing()
	{
		base.OnAppearing();
		await viewModel.LoadCommand.ExecuteAsync(null);
	}
}
```

`OnAppearing` is a page lifecycle method. It loads the latest rows whenever the page appears. All database and editing behavior remains in the view model.

## Troubleshooting guide

### The table does not exist

Confirm every database method awaits `initialization` before running a query.

### Every save creates a duplicate

Confirm the selected note keeps its nonzero `Id` and `SaveNoteAsync` calls `UpdateAsync` when `NoteId != 0`.

### The list does not update

Confirm the page binds to `ObservableCollection<Note>` and that `ReloadNotesAsync` runs after save and delete operations.

### The buttons never enable

Confirm the `[NotifyCanExecuteChangedFor]` attributes name the generated `SaveCommand` and `DeleteCommand` properties.

### The database is empty after relaunch

Confirm you used the same emulator or device and did not uninstall the app or clear its storage. Also confirm the app uses `FileSystem.AppDataDirectory` rather than a temporary cache directory.

### SQLite native-library error

Confirm that `sqlite-net-pcl` and its transitive dependencies restored successfully. Do not add unrelated SQLite packages at random. Inspect the resolved package list and rebuild the selected MAUI target.

- [ ] `sqlite-net-pcl` is installed.
- [ ] `CommunityToolkit.Mvvm` is installed and used.
- [ ] The database path uses `FileSystem.AppDataDirectory`.
- [ ] The `Note` model has an auto-incrementing primary key.
- [ ] Database initialization is awaited.
- [ ] Create, read, update, and delete all work.
- [ ] Database work is outside the page code-behind.
- [ ] The page uses dependency injection.
- [ ] `MauiProgram.cs` conditionally imports and registers the DevFlow agent with `MAUI_DEVFLOW`.
- [ ] The app is launched through the current .NET MAUI VS Code extension's DevFlow-enabled debugger.
- [ ] No permanent or independently pinned `Microsoft.Maui.DevFlow.Agent` package is present.
- [ ] Mac Catalyst includes the network-server entitlement when that target is used.
- [ ] XAML uses compiled bindings.
- [ ] The list uses `CollectionView`.
- [ ] The `CollectionView` is not inside a `StackLayout` or `ScrollView`.
- [ ] Blank notes cannot be saved.
- [ ] Database exceptions produce a readable status message.
- [ ] Notes remain after a full stop and relaunch on the same target.
- [ ] The running UI has non-zero bounds and readable input contrast.
